# Прогноз снижения покупательской активности клиентов интернет-магазина «В один клик»

Учебный проект курса «Специалист по Data Science» Яндекс Практикума, спринт «Обучение с учителем: качество модели».

## Постановка задачи

Интернет-магазин «В один клик» продаёт разные товары: для детей, для дома, мелкую бытовую технику, косметику и даже продукты. Отчёт за прошлый период показал, что активность покупателей начала снижаться. Привлекать новых клиентов уже не так эффективно — о магазине и так знает большая часть целевой аудитории. Возможный выход — удерживать активность постоянных клиентов с помощью персонализированных предложений.

Нужно построить модель, которая предскажет вероятность снижения покупательской активности клиента в следующие три месяца, а затем, используя предсказания модели и данные о прибыльности клиентов, выделить сегмент покупателей и предложить бизнесу, как удержать его активность.

## Данные

В каталоге `data/` четыре таблицы:

| Файл | Содержание |
|---|---|
| `market_file.csv` | поведение покупателя на сайте, коммуникации с ним, продуктовое поведение и целевой признак «Покупательская активность» |
| `market_money.csv` | выручка от покупателя за три последних периода |
| `market_time.csv` | время, проведённое покупателем на сайте, за два периода |
| `money.csv` | среднемесячная прибыль от покупателя за последние три месяца |

## Ход исследования

1. Загрузка и предобработка данных: пропусков и дубликатов не нашлось, исправлены две опечатки в категориях, удалён один клиент с аномально высокой выручкой.
2. Исследовательский анализ и отбор клиентов, покупавших во все три последних периода — осталось 1296 клиентов.
3. Объединение таблиц по `id` и корреляционный анализ (phik).
4. Обучение моделей в едином пайплайне (`Pipeline` + `ColumnTransformer` + `GridSearchCV`): кодировщик категориальных признаков закреплён за типом модели, скейлер количественных признаков подбирается на кросс-валидации.
5. Оценка важности признаков двумя методами — SHAP и перестановочным.
6. Сегментация покупателей и рекомендации для бизнеса.

## Модели

Перебирались четыре модели с подбором гиперпараметров:

* `KNeighborsClassifier`
* `DecisionTreeClassifier`
* `LogisticRegression`
* `SVC`

Метрика — ROC-AUC: бизнесу важно ранжировать клиентов по риску, а порог классификации будет выбран позже, исходя из бюджета маркетинга.

## Результат

Лучшая модель — **SVC с ядром RBF** (`C=0.1`, `gamma=0.1`) в связке с `OneHotEncoder` и `StandardScaler`:

| Выборка | ROC-AUC |
|---|---|
| кросс-валидация | 0.912 |
| тест | 0.911 |

Наибольший вклад в предсказание дают признаки вовлечённости клиента: число страниц за визит, время на сайте, число просматриваемых категорий и доля акционных покупок. Тип сервиса, разрешение на рассылку и отдельные категории товаров почти не влияют на предсказание.

Для работы выбран сегмент клиентов с высоким риском снижения активности (вероятность не ниже 0.6) и высокой прибыльностью (верхний квартиль) — 96 клиентов. У сегмента вдвое ниже вовлечённость на сайте, выше доля акционных покупок, вдвое больше неоплаченных корзин и меньше маркетинговых коммуникаций, чем у остальных. Бизнесу предложено показывать таким клиентам персональные подборки товаров, напоминать о неоплаченных корзинах с ограниченными по времени стимулами, заменить массовые акции персональными промокодами и выровнять частоту коммуникаций до среднего уровня.
